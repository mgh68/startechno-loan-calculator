# محاسبه‌گر طرح‌های اقساطی استارتکنو

وب‌اپ فارسی، واکنش‌گرا و مستقل برای مقایسه طرح‌های GSMPAY، دیجی‌پی و ازکی‌وام؛ مناسب **GitHub Pages**، بدون سرور، دیتابیس یا وابستگی اجرایی خارجی. **تم پیش‌فرض دارک** است؛ دکمه تغییر به لایت وجود دارد و انتخاب کاربر به‌صورت محلی ذخیره می‌شود.

## ساخت یک پروژه کاملاً مستقل در GitHub

1. در حساب GitHub خود روی **New repository** بزنید. نام پیشنهادی: `startechno-loan-calculator`.
2. مخزن را **Public** بسازید؛ به مخزن قبلی دست نزنید.
3. محتوای پوشه پروژه را در **ریشه مخزن** آپلود کنید (مخصوصاً `index.html`، `style.css`، `app.js` و `calculator.js`). به‌جای این کار، می‌توانید فایل ZIP را دانلود و بعد از استخراج، فایل‌های داخل آن را آپلود کنید.
4. وارد **Settings → Pages** شوید. در بخش **Build and deployment** گزینه **Deploy from a branch**، شاخه **main** و پوشه **/(root)** را انتخاب و Save کنید.
5. پس از انتشار، لینک مستقل شما به شکل `https://USERNAME.github.io/startechno-loan-calculator/` خواهد بود؛ به‌جای USERNAME نام کاربری خودتان را بگذارید.

> فایل HTML را مستقیم از File Explorer اجرا نکنید؛ چون از JavaScript Modules استفاده می‌کند. برای تست محلی، از یک HTTP server (مثلاً `python -m http.server 8000`) استفاده کنید و `http://localhost:8000` را باز کنید.

## ویژگی‌ها

- فارسی و راست‌چین؛ طراحی مخصوص موبایل بدون اسکرول افقی.
- معرفی شرایط و مدارک در پنجره بازشو، بدون جابه‌جایی فرم محاسبات.
- GSMPAY بلو ۱۲ماهه و های‌بانک ۲۴ماهه، کارمزد اعتبار ۱۴٫۵٪ نقدی و اختلاف نقد/اقساط ۳٪ کل فاکتور؛ اعتبار بالاتر از فاکتور به‌صورت خودکار ارائه نمی‌شود.
- دیجی‌پی ۱۲ماهه با چهار اعتبار **ثابت** ۷۰/۱۰۰/۱۵۰/۲۰۰ میلیون؛ روش پرداخت اشتراک ۱۴٫۵٪: نقدی یا کسر از اعتبار؛ اختلاف نقد/اقساط ۹٪ کل فاکتور.
- توضیح BNPL دیجی‌پی در شرایط بدون محاسبه چهار قسطه.
- ازکی‌وام ۶/۱۲/۱۸/۲۴ماهه، به ترتیب ۸٪/۱۵٪/۱۹٫۵٪/۲۴٪ کارمزد کسرشده از اعتبار، اختلاف نقد/اقساط ۴٪ کل فاکتور. طرح ۶ ماهه تا ۳۰۰ میلیون؛ طرح ۱۲ماهه تا ۱۰۰ میلیون؛ طرح‌های ۱۸ و ۲۴ماهه تا ۳۰۰ میلیون. حداقل ازکی‌وام ۳۰ میلیون.
- اقساط و سود تمام طرح‌ها با سود بانکی سالانه ۲۳٪ و فرمول اقساط مساوی (تقریبی).
- ورودی قیمت فاکتور، اعتبار دلخواه اختیاری، گام گرد کردن پیش‌فرض ۱۰ میلیون، مدت دلخواه (یا همه دوره‌ها)، نحوه پرداخت اشتراک دیجی‌پی.
- در حالت خودکار، پیشنهاد اعتبار برابر فاکتور، رند پایین‌تر، نزدیک پوشش هزینه‌ها و پوشش کامل (در صورت انطباق با محدودیت مازاد مؤثر حداکثر ۵٪ فاکتور).
- در حالت دستی، فقط همان مبلغ و مدت‌های مجاز محاسبه می‌شود. اعتبارهای غیرمجاز دیجی‌پی به جای تبدیل خودکار رد می‌شوند.

## توجه مهم به روش کارمزدها

- **اختلاف خرید نقد و اقساط همیشه درصدی از کل فاکتور است**، نه اعتبار بانکی.
- **GSMPAY:** ۱۴٫۵٪ اعتبار باید نقدی پرداخت شود، و از اصل اعتبار کسر نمی‌شود. نقدی لازم = کسری فاکتور از اعتبار + ۳٪ فاکتور + ۱۴٫۵٪ اعتبار.
- **دیجی‌پی:** در روش پرداخت نقدی اشتراک، اعتبار بانکی کامل می‌ماند و ۱۴٫۵٪ اعتبار نقدی پرداخت می‌شود. در روش کسر اشتراک، ۱۴٫۵٪ اعتبار + ۹٪ فاکتور از اعتبار مؤثر کسر می‌شود.
- **ازکی‌وام:** کارمزد ارائه اعتبار براساس مدت، به همراه ۴٪ فاکتور از اعتبار مؤثر کسر می‌شود.
- **پوشش هزینه‌ها:** فقط وقتی در حالت پیشنهاد خودکار نشان داده می‌شود که اعتبار مؤثر نهایی بین ۱۰۰٪ تا ۱۰۵٪ مبلغ فاکتور باشد. این شرط با اجازه قانونی/قراردادی استفاده از اعتبار مازاد تفاوت دارد و باید جداگانه تأیید شود.

## ساختار

```
index.html        رابط صفحه
style.css         تم دارک/لایت و طراحی واکنش‌گرا
calculator.js     فرمول‌ها و قوانین خالص بدون وابستگی به DOM
app.js            رابط تعاملی، فرم، نتایج و معرفی مدارک
package.json      اجرای تست‌ها (برای سایت ضروری نیست)
tests/            تست فرمول‌ها و سناریوهای مرجع
```

## محدودیت‌ها و فرضیات

شرایط شرکت‌ها مطابق اطلاعات اعلام‌شده توسط صاحب فروشگاه تنظیم شده‌اند و ممکن است تغییر کنند؛ قبل از انتشار برای مشتری، شرایط قرارداد و بانک کنترل شوند. محاسبه سود سالانه ۲۳٪ با فرمول اقساط مساوی و نرخ ماهانه ۲۳٪ تقسیم بر ۱۲ است؛ اقساط قطعی بانک ممکن است بر اساس روزشمار، بیمه، مالیات، گرد کردن یا جدول اختصاصی متفاوت باشند. در پیشنهادهای پوشش هزینه‌ها صرفاً امکان‌سنجی ریاضی صورت می‌گیرد؛ قرارداد ممکن است استفاده از اعتبار بیشتر از بهای واقعی فاکتور را ممنوع کند.

برای تغییر نرخ/سقف/درصد هر طرح، آرایه `SCHEMES` در `calculator.js` را ویرایش کنید.

## نسخه ۲
- لوگوهای ارسالی در پوشه `assets/` با فرمت WebP شفاف؛ فایل‌های آن پوشه نیز باید در GitHub بارگذاری شوند.
- مبالغ به تومان کامل نمایش داده می‌شوند؛ فیلدهای عددی هنگام تایپ جداکننده هزارگان دارند.
- آکاردئون هر کارت به‌طور مستقل و با لمس سرتاسر نوار عنوان باز و بسته می‌شود.


## نسخه ۳ — اطلاعات فروشگاه و فونت
- در سربرگ لینک مستقیم **https://startechno.ir/** قرار دارد.
- متن معرفی فروشگاه: «فروش نقد و اقساط انواع گوشی، لپ‌تاپ، کنسول و لوازم جانبی از فروشگاه حضوری و سایت استارتکنو».
- تم دارک حالت پیش‌فرض است؛ تم لایت نیز به کمک دکمه تغییر تم فعال می‌شود.
- لوگوها با WebP واقعی دارای آلفای شفاف (نه وکتور؛ WebP یک قالب تصویری پیکسلی است) در `assets/` قرار دارند.
- برای خوانایی لوگوهای سفید/تیره روی هر دو تم، فیلتر نمایشی CSS متناسب با تم تنظیم شده است؛ **فایل اصلی لوگو دست‌کاری مجدد نشده است**.
- فونت‌های نازنین معمولی و بولد از مسیرهای `fonts/BNAZANIN(1).TTF` و `fonts/BNAZNNBD(1).TTF` بارگذاری می‌شوند. **فایل‌های فونت در بسته قرار نگرفته‌اند.** دو فایل فونتی را که خودتان فرستاده‌اید، جداگانه داخل این پوشه در GitHub بارگذاری کنید. بدون آنها فونت جایگزین استفاده می‌شود.
- تمام مبالغ نمایش‌داده‌شده در نتیجه به تومان کامل، با گروه‌بندی سه‌رقمی هستند. در کادرهای مبلغ نیز جداکننده هزارگان هنگام تایپ درج می‌شود.
- باز شدن نوار جزئیات هر نتیجه مستقل است و باعث کشیده شدن کارت کناری نمی‌شود.

### به‌روزرسانی مخزن موجود
به‌جای ساخت مخزن جدید، فایل‌های این نسخه را در مخزن فعلی `mgh68/startechno-loan-calculator` آپلود و جایگزین کنید. پوشه `assets/` باید در ریشه مخزن قرار بگیرد. اگر فایل‌های HTML و JS یا CSS در پوشه‌ای اضافه قرار بگیرند، GitHub Pages آنها را پیدا نمی‌کند.
